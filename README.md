# Hotel Booking Analytics 🚧 (en cours)

Analyse de données de réservations hôtelières (données Booking / Expedia) :
nettoyage, exploration SQL et recherche des facteurs qui influencent le
volume de réservations, le tarif moyen et le taux d'annulation.

## Contenu

| Dossier / fichier | Description |
|---|---|
| `notebooks/01_exploration.ipynb` | Exploration et nettoyage initial du jeu de données (87 000 lignes). |
| `notebooks/02_sql_exploration.ipynb` | Exploration des données via SQL. |
| `sql/01_comparaison_hotels.sql` | Comparaison des hôtels : volume de réservations, tarif moyen (ADR), taux d'annulation. |
| `data/processed/hotel_bookings_clean.csv` | Jeu de données nettoyé, prêt pour l'analyse. |

## Questions explorées

- Quel hôtel génère le plus de volume d'activité ?
- Quel hôtel pratique les tarifs les plus élevés en moyenne ?
- Quel hôtel a la clientèle la plus fiable (celle qui annule le moins) ?
